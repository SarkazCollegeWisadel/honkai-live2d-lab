# Honkai Live2D Lab

为《崩坏3》月下誓约·予爱以心（大月下）与繁星·绘世之卷（小格蕾修）规划可编辑的 Live2D 角色，以及可复用的 AI 互动、TTS、面捕和 Paper2Galgame 接入流程。

**当前阶段：需求确认与技术调研。仓库目前只有规划文档，没有可下载使用的角色模型，也没有经过运行验证的 P2G 适配程序。**

## 已确定的目标

- 先完成大月下默认服饰，再制作一套经用户审阅的常服，随后复用流程制作小格蕾修。
- 全身精细制作、以半身展示为主；首版仅站姿，预留换装结构。
- 官方立绘倾向的精致画风，追求丰富自然的 VTuber 表演效果。
- 优先做好正常、疑惑、开心、娇嗔、wink、微笑，头发、服饰与饰品摆动自然可爱。
- P2G 内自动演出；独立聊天程序可接 LLM、外接 TTS 和本地 TTS。
- 同一模型另外支持普通摄像头面捕；不要求在 P2G 内直接面捕。
- 优先成熟项目和可扩展性，接受 Cubism、VTube Studio 与开源工具混用。
- 保留分层立绘、可编辑建模工程、动作表情、驱动配置、自定义代码与制作记录。

这是非官方的个人学习项目，与 HoYoverse、Live2D、P2G 及候选开源项目无隶属关系。

角色、美术、第三方模型、SDK 与依赖分别保留其来源和适用条款。仓库公开不意味着所有参考素材可以重新分发。未经确认可分发的第三方立绘、模型展示视频、游戏安装文件、TTS 权重和音色素材不纳入公共提交。
