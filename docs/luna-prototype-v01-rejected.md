- 自动拆层重绘了面部；PSD 中脸底仅 88×92，嘴部仅 14×5，无法支撑目标精度。
- 裙装的遮挡补绘盖住了部分腿部，重组后服装外观偏离原图。

- 自动绑定流程会修改图层顺序，并将头饰抬到前发上方；此启发式可能影响本角色，应通过关闭单个处理步骤做对照，不能直接归因为唯一原因。
