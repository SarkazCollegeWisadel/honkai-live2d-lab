## 拆层方式

先用 See-through 官方云端演示进行低分辨率工艺验证，检查能否获得真正的多层 PSD、遮挡补绘和左右肢体。试跑结果不直接当最终立绘。正式制作保留输入、随机种子、分辨率、版本、原始 PSD、修订 PSD 和最终绑定工程。

自动结果需要进一步细分以下部分；同一项可按变形需要拆成多层：

| 部位 | 需要独立控制的内容 | 主要验收 |
| --- | --- | --- |
| 头部 | 脸底、左右耳、颈部、阴影 | 左右转头时头发下的脸部完整，颈部不露缝 |
| 眼睛，每侧独立 | 眼白、虹膜、瞳孔、高光、上睫毛、下睫毛、双眼皮、眼睑阴影 | 单眼闭合、笑眼、凝视和眨眼叠加不穿帮 |
| 眉毛 | 左右眉、额前遮挡 | 疑惑的不对称眉位和娇嗔均可读 |
| 嘴 | 上下唇线、口腔、舌、上齿、下齿、必要遮罩 | 微笑与说话叠加，闭嘴无黑缝 |
| 头发 | 刘海多束、左右侧发、前发、后发多束、卷曲发梢 | 遮挡有补绘，发束摆动不成整块纸片 |
| 头饰与耳饰 | 左右头饰、飘带、耳坠 | 随头部轻摆，惯性弱于长发 |
| 上身 | 肩、上臂、前臂、手掌与手指、袖口、胸前花饰 | 保持站姿，不要求手捕；呼吸与身体摆动无接缝 |
| 服装 | 领饰、紧身衣、腰饰、前裙、左右裙摆、内衬、后拖尾、金属饰物 | 前后关系正确，裙摆惯性可独立调整 |
| 下身 | 左右腿、腿饰、袜、鞋、鞋饰 | 全身展示完整，半身模式不影响物理稳定 |

换装以独立服装组组织；脸、眼、口、通用头发及身体基础尽量复用。尚未制作或承诺裸身底图；服装遮挡补绘只需满足穿着状态和转向范围。

## 参数和演出目标

以下为项目拟定目标，数值以实际模型极值测试调整，不是当前已完成能力。

- 头部 X/Y/Z：目标左右和俯仰约 ±30°，Z 约 ±20°；必须验收四角组合。
- 身体跟随：弱于头部，避免脸转动时躯干保持僵直。
- 左右眼独立开合与笑眼；目光、左右眉独立；嘴开合与嘴形分开。
- 呼吸、头发、飘带、耳饰和裙摆分组物理；阻尼与摆幅按材质区别设置。
- normal 平静，confused 轻偏头与不对称眉，happy 明显笑眼，pout 轻皱眉与撅嘴，wink 单眼闭合，smile 轻微笑意。开心和微笑必须有区别。
- AI 表情、嘴型和面捕要有控制权切换；面捕开启时禁止待机持续覆盖同一头部参数。

## 绑定与交付验收

1. PSD 是多层可编辑文件，关闭一层能看到实际遮挡补绘；不能将单张透明 PNG 放入 PSD 后标记为拆层完成。
2. cmo3 在 Cubism Editor 打开，无损坏提示；修改参数保存并重新导出成功。
3. moc3 与 model3、textures、physics3、exp3、motion3 资源完整，三端实际加载。
4. 六表情连续切换、说话时切换、停止语音、应用重启和摄像头模式均通过。
5. 全身与半身两种构图、常服扩展分别验收。
